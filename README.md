# ColonyPy
Automated fungal colony detection and classification for antifungal tolerance, heteroresistance and susceptibility research, powered by StarDist deep learning

⚠️ **Security Notice**

ColonyPy is not commercially code-signed as this is an academic research tool. Your operating system may display a security warning when launching it for the first time. This is expected, the software is safe to use.
Windows: Click "More info" → "Run anyway"
macOS: Go to System Settings → Privacy & Security → scroll down and click "Open Anyway"
