Overview

ColonyPy automates the counting and classification of fungal colonies on petri dish images. It uses a trained StarDist deep-learning model to detect individual colonies, measures their size, and classifies each colony as either:

  • Tolerance smaller than the control-derived median colony size (grows under drug pressure)
  • Heteroresistance same size or larger than the control median (potentially resistant sub-population)

The classification threshold is derived automatically from matching control plates (no-drug) using the same strain. No manual threshold setting is required when control plates are present.

Launching ColonyPy

ColonyPy is distributed as a standalone executable built with PyInstaller. No Python installation, no command line, and no internet connection are required on the user's machine. Everything including the trained StarDist model and all dependencies is bundled inside the executable.

Windows

Double-click ColonyPy.exe

Windows may show a SmartScreen warning on first launch. Click More info → Run anyway.

macOS

Double-click ColonyPy.app

On first launch, right-click → Open → Open. You may need to allow it in System Settings → Privacy & Security.

Linux

Run ./ColonyPy/ColonyPy from a terminal, or double-click if your file manager supports it.

First Launch Slow Start
On the very first launch, the executable may take 15–30 seconds to start while it unpacks its bundled libraries. Subsequent launches are faster. This is normal behaviour for PyInstaller executables.

Good Practice Guidelines

Inoculum Preparation

Critical: Control Plate Inoculum Concentration

ColonyPy uses StarDist, a convex shape detection model. It is designed to detect convex colonies. It cannot detect colonies within confluent lawns.

Using too high an inoculum in strain control plates will cause:

  • Unreliable threshold calibration from control plates

Recommended practice:

  • Optimise inoculum concentration so that colonies on the control plate are well-separated
  • Control plates should produce distinct, non-overlapping colonies across the whole plate
  • Aim for 100-500 countable colonies per plate
  • Dutring testing, if the ZOI shows a lawn, dilute the inoculum and repeat

Plate Preparation

  • Use standard 90 mm round petri dishes, any other sizes require parameter adjustment
  • Ensure the tray is clean before imaging. Residue on the tray creates bright spots that may be detected as colonies
  • Place only one plate per image. ColonyPy analyses one plate per image file
  • Remove the plate lid before imaging
  • Ensure the plate is upright, resting on its bottom, with the agar surface facing up
  • Do not image plates with writing on the bottom or along the sides, as markings interfere with analysis
  • Ensure the plate is centred and fully in frame with no shadows cut across it

Critical: Plate Cleanliness

  • The agar surface, plate rim and plate bottom must be free of artefacts, bubbles, condensation, or media residue. Any dark marks near the plate edge can disrupt the plate-boundary detection algorithm.

Re-run and Overwrite Policy

Important: Output Directory Policy

ColonyPy writes results into the output directory you specify. If you re-run an analysis with the same output directory, the colony_analysis_results.csv file is overwritten for any image that is re-processed.

Best practice: always use a new, separate output directory for each re-run. This preserves your original results and avoids accidental data loss. Use clear naming such as:

  • results_2025-06-01_run1/
  • results_2025-06-01_run2_adjusted_ZOI/

File Naming Convention

Correct file naming is essential for ColonyPy to match control plates to test plates of the same strain and to group replicates for statistics.

What happens if naming is wrong? Files will be listed as invalid and skipped entirely, no error will be shown for individual files, the run will just produce no results.

Plate TypeFormatExample
Control plate{n}_{strain}_C.jpg1_gpr4.5_C.jpg
Test plate{strain}_rep{n}_{condition}.jpggpr4.5_rep1_8ug.jpg
  • Control plates must end with _C (case-insensitive) before the file extension
  • The strain identifier must match between control and test plates
  • Conditions and replicate numbers are used for grouping statistics
  • Supported formats: .jpg, .jpeg, .png, .bmp, .tiff, .tif

What actually happens when a run is performed without controls?

In Agar dilution mode

  • If no control plates exist at all in the folder → analysis stops immediately with "No control plates found" and returns no results
  • If a control exists for some strains but not others → test plates for the unmatched strains are silently skipped with a console message only; they won't appear in output or CSV
  • If a control plate is present but colony detection fails on it → that strain's threshold falls back to the hardcoded default of 12 px, and percentages will be 0%

In Disk diffusion mode

  • If no control plates exist at all in the folder → analysis will proceed and all test strain threshold falls back to the hardcoded default of 12 px
  • If a control exists for some strains but not others → test plates for the unmatched strains threshold will use the default 12 px, while matched test plates will utilise cntrol colony median threshold

Manual Boundary Adjustments

Occasionally the automatic boundary detection is imprecise. The editor provides sliders to correct this before re-detecting colonies.

Adjusting the ZOI Boundary (Disk Diffusion)

The ZOI (Zone of Inhibition) boundary is the circle around the disk within which colonies are counted. If it is too tight or too wide:

  1. In the Manual Editor left panel, find the ZOI Boundary slider
  2. Drag the slider left to shrink the ZOI or right to expand it
  3. The yellow dashed arc on the image updates in real time
  4. Click Re-detect Colonies to rerun StarDist detection with the new boundary
Re-detection
When you click Re-detect Colonies, the full analysis pipeline (sharpening → CLAHE → reference standardisation → StarDist) runs again with your new boundary. This is identical to the original automated analysis not a simple filter of old results.

Adjusting the Disk Size

If the disk detection is slightly off (disk circle too large or too small over the actual disk):

  1. Find the Disk Radius slider in the editor left panel
  2. Adjust until the grey disk overlay matches the physical disk in the image
  3. Click Re-detect Colonies colonies that overlap the disk exclusion zone will be removed

Adjusting the Plate Boundary

The green circle should sit precisely on the inner edge of the petri dish rim. If it is too large (picking up false colonies on the rim) or too small (missing edge colonies):

  1. Find the Plate Radius slider in the editor left panel
  2. Drag left to shrink the boundary (excludes more rim) or right to expand it
  3. For agar dilution plates where the rim is thick or falsely bright, shrink the plate radius until the green circle sits clearly inside the rim
  4. Click Re-detect Colonies
Wide Rim / False Edge Colonies in Agar Dilution analysis mode

In full-plate (agar dilution) analysis, the plate rim often produces bright artefacts that are mistaken for colonies. This is the most common cause of inflated counts in agar dilution mode.

Fix: Reduce the Plate Radius slider by 5–15 pixels until the false rim colonies disappear from the overlay, then click Re-detect Colonies. Apply the same adjustment consistently across all plates in the same batch.

Adjusting the Colony Size Threshold

If the boundary between Tolerance and Heteroresistance colonies is set incorrectly (e.g. all colonies appear one colour):

  1. Find the Colony Threshold spinner in the editor
  2. Increase the value to reclassify more colonies as Tolerance (fewer Heteroresistance)
  3. Decrease to classify more as Heteroresistance
  4. Click Apply Threshold colonies reclassify immediately without re-detection

Note: When a control plate is matched, this threshold is set automatically from the control median colony size. Manual adjustment overrides this only for the current image.

It is recommended not to adjust the threshold and use a control plate is matched, this threshold is set automatically from the control median colony size.

Re-opening Saved Sessions

Every image processed through the manual review workflow has its session saved automatically in editing_sessions/ inside your output folder. You can reload any session to review or redo it.

To Load a Saved Session

  1. Go to Tools → Load Editing Session
  2. Navigate to your output folder → editing_sessions/
  3. Select the *_session.json file for the image you want to review
  4. The editor opens showing the image with all previously saved colony annotations
  5. Make any corrections, then use Continue to re-save
Session Files
Session files (*_session.json) store all colony positions, classifications, and boundary parameters from the last editor save for that image. They do not include the image itself the original image file must be accessible at its original path (or in the input directory).

Re-runs and Result Overwriting

Always Use a New Output Directory for Re-runs

ColonyPy updates colony_analysis_results.csv by overwriting rows for any image that is re-processed. If you re-run with the same output directory, your previous results for that image are replaced with no confirmation prompt.

To preserve all versions of your results:

  1. Create a new output folder before each re-run (e.g. run2_adjusted_boundary/)
  2. Set this as the output directory in the Setup tab
  3. Run analysis as normal

Batch summary (BATCH_SUMMARY_*.csv) and replicate statistics (REPLICATE_STATISTICS_*.csv) files are timestamped and never overwritten. A new file is created each time analysis completes.

Two-Stage Accuracy

The model achieves approximately 80% automated recall. After manual review using the editor (adding missed edge colonies, removing false positives), effective accuracy reaches 95–99% for well-prepared plates. This is why the manual review workflow is recommended for published results.

Training Image Conditions

All training images were acquired under these exact conditions:

  • Light application: Coomassie Blue
  • Imager: Bio-Rad ChemiDoc, white transillumination mode
  • Exposure: 0.9 seconds
  • Size: Medium 1830 × 1646 pixels, 300 DPI, 24-bit colour, 15.5 × 12.4 cm
  • Plate: Standard 90 mm petri dish

The model is expected to perform best on images that closely match these conditions. Images from different imagers, different exposure times, or different lighting protocols may give reduced accuracy.

Image Preprocessing Pipeline

Before StarDist runs, each image goes through the following pipeline:

  1. Unsharp mask sharpening (disk diffusion only) amount = 1.5, sigma = 5.0 px. Applied to colour image before grayscale conversion.
  2. Grayscale conversion
  3. CLAHE contrast-limited adaptive histogram equalisation (clip limit 3.0, 8×8 tile grid)
  4. Reference standardisation intensity profile matched to the training dataset mean and standard deviation
  5. StarDist normalisation percentile stretch (1st–99.8th) before model inference

Control plates and agar dilution plates are not sharpened, sharpening is only applied to disk diffusion test plates.

Troubleshooting

Disk not detected / disk detection failed

ColonyPy uses a Hough circle transform to find the disk. This fails if:

  • The disk is at the very edge of the frame, ensure the full plate is visible
  • The tray has smudges or bright spots near the disk size range
  • The image is very dark or overexposed, check your 0.9 s exposure setting

If detection fails, ColonyPy will ask if you want to skip the image. Use the Manual Editor to open the image directly and set the disk position manually.

All colonies classified as Heteroresistance

This typically means the threshold is set incorrectly:

  • Verify that the matching control plate file is in the input directory and named correctly (must end with _C)
  • Check that the strain identifier in the control filename matches the test plate
  • In the editor, increase the Colony Threshold value and click Apply Threshold
False colonies detected on the plate rim

The inner surface of the petri dish rim often produces a bright ring of artefacts. To fix:

  1. Open the editor for the affected image
  2. Reduce the Plate Radius slider until the green boundary circle sits inside the rim
  3. Click Re-detect Colonies
  4. Apply the same radius adjustment to all plates in the batch for consistency
Fewer colonies detected than expected near the ZOI edge

Colonies at the outer edge of the ZOI are often lower contrast and may be missed by automated detection. This is normal, the model has ~80% automated recall. Use manual review to add missed edge colonies:

  1. In the editor, select Add Tolerance or Add Heteroresistance mode
  2. Click on each missed colony
  3. Alternatively, expand the ZOI boundary slightly using the ZOI slider and Re-detect
Lawn in the ZOI

If colonies have grown into a confluent lawn, ColonyPy cannot count individual colonies. The model is designed for convex, colonies only. Solutions:

  • Repeat the experiment with a lower inoculum concentration
  • The lawn colony clusters will be detected as single large heteroresistance colonies, this is not biologically meaningful and should not be included in analysis
StarDist not installed / model not found

This should not occur with the PyInstaller executable as StarDist and the model are bundled inside. If you see this error:

  • Re-download the ColonyPy executable the download may have been corrupted
  • Ensure you are running the correct executable for your platform (Windows .exe, macOS .app, Linux binary)
  • On macOS, make sure you extracted the .zip fully before launching do not run directly from inside the zip
  • If running from source (developer), ensure model_data/weights_best.h5 exists in the same folder as the .py files
Analysis is very slow

StarDist inference time depends on image size and hardware. On a standard laptop (no GPU), each image takes 30–120 seconds. To reduce analysis time:

  • Close other applications while ColonyPy is running
  • If you have a supported GPU, TensorFlow will use it automatically
⚠ TIFF Images

TIFF images take longer to be analysed due to their large file size. This is especially noticeable if your system's RAM is running low

Frequently Asked Questions

Can I use images from a different imager?

The StarDist model was trained exclusively on images from a Bio-Rad ChemiDoc with Coomassie Blue light application at 0.9s exposure. Images from other imagers may have different contrast profiles that reduce detection accuracy. If you use a different system, we recommend validating manually on a representative subset of images before using results for publication.

Do I need a control plate for every strain?

Yes. The classification threshold is derived from the median colony size on the matched control plate. Without a control plate, ColonyPy uses the default threshold (12 px by default), which is unlikely to be calibrated for your strain. Always include at least one control plate per strain per batch.

Can I analyse multiple plates per image?

No. ColonyPy expects one plate per image. Use the ChemiDoc imaging software to capture separate images for each plate.

What does the CV warning in replicate statistics mean?

CV (coefficient of variation) measures variability across replicates. A "HIGH VARIABILITY" flag appears when CV exceeds the threshold for that metric (e.g. 20% for total colonies). High CV may indicate: inconsistent inoculum between replicates, variable culturing, imaging artefacts, or biological variability. Investigate flagged groups before reporting.

How do I report ColonyPy in a methods section?

Suggested methods text:

Please cite the ColonyPy publication once it becomes available Atim et al., 2026 (when available). Colony images were acquired using a Bio-Rad ChemiDoc imaging system (white transillumination mode, 0.9 s exposure, Coomassie Blue light application; 1830 × 1646 pixels, 300 DPI, 24-bit colour, 15.5 × 12.4 cm physical size). Colony detection and classification were performed using ColonyPy v1.0 (Nielsen Laboratory), which implements a StarDist deep-learning segmentation model (F1 = 80.5%, precision = 82.9%, recall = 78.2%, trained on 60 images). Colonies were classified as Tolerance or Heteroresistance based on size relative to the median colony area of strain-matched no-drug control plates. Automated detections were reviewed and corrected using the ColonyPy manual editor.
How do I save settings between sessions?

Use File → Save Settings… to save your current parameters (directories, method, colours, thresholds) to a JSON file. Load them again with File → Load Settings… at the start of your next session.
